# Python User Account System
A beginner Python project that implements a simple console-based sign-up and sign-in system.

## Features

- Create a new account with a unique username.
- Validate username length.
- Confirm passwords during registration.
- Sign in using an existing username and password.
- Limit failed password attempts.
- Handle invalid user input.

## Technologies

- Python 3
- Dictionaries
- Loops and conditional statements
- String operations and input validation

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python3 acount.py
```

## Limitations

This is a beginner learning project. Account information is stored in memory and is lost when the program terminates. Passwords are stored as plain text, so this implementation is not suitable for real-world authentication.

## Purpose

Built to practise Python dictionaries, loops, conditional logic, input validation, and program flow through a practical project.
